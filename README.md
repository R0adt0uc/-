# 三角洲音效插件v1

能让你的威龙变豪？

Windows 64 位本地按键音效工具。已附带运行环境，**无需安装 Python、pygame 或其他依赖**，使用时无需联网。

## 下载

Windows 用户请从 [Releases](https://github.com/R0adt0uc/-/releases) 下载完整运行包。仓库源码 ZIP 不含运行环境和音频素材。

## 快速使用

1. 将整个压缩包解压到一个可写的文件夹，不能只取出 EXE，也不要在压缩包内直接运行。
2. 如需改键，双击 **设置.bat**；依次设置喷气、C4、虎蹲炮和总开关键，直接回车保留当前值。
3. 右键 **启动程序.exe** → **以管理员身份运行**，以匹配已测试成功的游戏使用方式。
4. 程序窗口可以最小化；关闭窗口退出并停止全部声音。一次只运行一份。
5. 音效输出到 Windows 默认播放设备；只想在耳机听到时，请把耳机设为默认设备。

## 默认按键

| 按键 | 功能 |
| --- | --- |
| X（喷气） | 随机播放“我从来都不会输”或“我来同你玩” |
| G（C4） | 播放“我来同你玩” |
| Z（虎蹲炮） | 随机播放“还未到收手的时候”或“我做嘢，你一百个 percent 放心” |
| 0 | 开启/关闭全部功能，关闭立即停声并清空连按记录 |
| + / = | 本程序音量增加 10%，主键盘无需按 Shift |
| - | 本程序音量减少 10% |

长按只触发一次，松开再按才算下一次。随机语音可能连续相同。语音和音乐可以同时播放；再次触发语音会替换上一句。

音量范围 0%–100%，不影响系统和游戏音量。数字小键盘 +/- 也支持。每次启动默认功能开启、音量 100%。关闭功能期间只有总开关键响应；重新开启不会自动续播。

## 音乐规则

在 **2 秒内**完整按出以下任意一组，相邻按键间隔必须 **小于 1 秒**：

`131313` / `313131` / `232323` / `323232`

支持主键盘及数字小键盘。有效动作会开始播放约 67 秒的完整版音乐。

- 同组继续快速交替切换，会以最后一次有效切换刷新计时。连续切换 8 次，从最后一次开始算。
- 零散切换不会延长音乐；间隔达到 1 秒、重复同一个数字、换一组数字或中途新按其他键，会结束当前组，需要重新完成有效动作。
- 距最后一次有效切换满 8 秒，开始 3 秒平滑淡出。
- 淡出期间完成新的有效动作，会恢复音量并继续当前位置，不重播、不叠加。
- 完全淡出或自然播放结束后，下次有效动作从头播放。整首播完不自动循环。

## 修改按键

使用 **设置.bat**，四个功能可自行设置，支持字母、数字、F1–F24、SPACE、TAB、NUM0 等单键名称，不支持组合键。

四项不能重复；1、2、3 和 +/- 为音乐及音量保留。0 同时包含主键盘和数字小键盘，NUM0 仅代表数字小键盘。

直接回车保留当前值，Ctrl+C 取消且不保存。保存后请关闭旧程序并重新启动。配置保存在 `其他/按键设置.json`，不需要手动编辑。

## 常见问题

- **缺少 DLL / 无法启动**：重新完整解压，确保“其他”文件夹与 EXE 一起保留。适用于 Windows 64 位，不是 macOS 或手机版。
- **游戏前台不响应**：关闭旧程序，以管理员身份启动；检查当前保存的按键和总开关状态。
- **听不到声音**：检查默认播放设备、程序音量及 Windows 音量混合器。
- **声音重复**：检查是否同时运行了多份。
- **改键没生效**：保存后需要重启程序。
- **音乐不触发**：必须完整按出六次，2 秒内完成、间隔小于 1 秒，且不要插入其他按键。

程序按物理按键触发声音，不识别技能是否释放成功或冷却。开启时，在其他软件里按对应键也会响应。

## 从源码运行

安装 Windows 64 位 Python 3.10，先从正式版运行包中将“音频”文件夹复制到仓库根目录，再执行：

```powershell
python -m pip install -r requirements.txt
python launcher.py --settings
python launcher.py
```

源码为当前正式版本，音频包含在运行包内；打包 EXE 和完整 ZIP 通过 GitHub Releases 分发。
个人按键配置不提交到仓库，首次运行使用 X/G/Z/0 默认值。
